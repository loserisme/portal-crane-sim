# 四连杆水平变幅抓斗门座式起重机 · 运动仿真

浏览器端抓斗门座式起重机运动仿真：**船舱抓沙 → 回转变幅 → 卸入卡车**。
纯前端实现，无构建、无依赖安装，**双击 `index.html` 即可运行**（three.js 已本地内置）。

结构：**象鼻梁 + 大拉杆四连杆水平变幅 + 塔架 + 齿条变幅机构 + 转台后上方圆盘平衡重 + 双颚抓斗**。整机比例参照用户的 SolidWorks / FBX 整机模型（轨距 10.0 / 基距 12.6 / 门架净空 10.5）。

## 2. 四连杆水平变幅

```
B = A + L₁·u(α)                      臂架头
D ← |DB| = r_d，|DE| = L₃ 两圆交点    大拉杆连接点
C = B + r_c·u(φ_BD + β)              抓斗悬挂滑轮
```

| 参数 | 数值 |
|---|---|
| 象鼻梁 \|BC\| | 8.68 m |
| \|BD\| | 2.77 m |
| ∠CBD | −139.2° |
| 大拉杆 \|DE\| | 25.88 m |

**α 从 26° 到 50° 全程，抓斗滑轮点 C 的高度极差仅 0.29 m**——水平变幅由四连杆几何实现，不需要卷筒补偿。

## 3. 齿条变幅机构

臂架根部装扇形齿条（节圆半径 2.30 m，包角 44°），与转台上的小齿轮（r = 0.42 m）啮合，**中心距 2.72 m = 两节圆半径之和**，保证齿面接触；减速箱紧贴小齿轮后下方布置。

## 4. 平衡机构

转台后上方设摆动杠杆（铰点 (−2.20, 7.50)，臂长 3.60 m），末端装 ⌀3.24 m 圆盘配重，两根连杆接到臂架根部。杠杆随臂架反向摆动（θ ≈ −0.50α），配重升降抵消倾覆力矩。杠杆铰点下方设支座，落在机房顶上。

### 抓取量计算

斗内物料不是固定值，闭斗瞬间按下面三项相乘确定填充率：

```
fill = 插入深度系数 × 开度系数 × 料层系数
```

| 因子 | 计算 | 说明 |
|---|---|---|
| 插入深度系数 | `clamp((料面高度 − 抓斗底高度) / 1.15, 0, 1)` | 插入 1.15 m 即满斗；在料面上方闭斗抓空 |
| 开度系数 | `clamp((闭斗前最大开度 − 0.25) / 0.68, 0, 1)` | 全开为 1；半开 50% 只剩 0.37；小于 25% 抓不到 |
| 料层系数 | `clamp(舱内余量 × 1.6, 0.12, 1)` | 见底时抓不满 |

舱内料面随累计抓取下降（满载 2.55 m → 见底 1.05 m），舱容 14 斗。每抓一次料面下沉，后面几斗自然越抓越浅，直到需要把抓斗放得更低。

实测（料面 2.55 m、全开闭斗）：

| 抓斗底高度 | 插入深度 | 填充率 |
|---|---|---|
| 1.20 m | 1.35 m | 100% |
| 2.00 m | 0.55 m | 48% |
| 2.60 m | 0 | 0（空斗） |
| 1.20 m，开度 50% | 1.35 m | 37% |

卸料只在**张斗动作**时发生（开度在增大且超过 35%），闭斗过程不会漏料。料流尽且抓斗位于车斗上方时，卡车装载计数 +1。

## 6. 作业循环

点击「作业循环」自动执行：

1. **抓斗下降入舱** —— 回转 −90°、幅度 35 m，抓斗落至舱内沙面
2. **闭合抓取** —— 颚板合拢，斗内装满沙
3. **提升出舱** —— 升至 15.5 m，高于舱口围板
4. **回转至卡车上方** —— 回转 −90°→0°，同时微调变幅保持抓斗高度
5. **下降就位** —— 降至车斗上方 5 m
6. **张开卸料** —— 沙流落料，卡车装载量 +1
7. **提升 → 回转复位** —— 返回船舱

卡车装满 3 斗后自动清零（模拟换车）。

## 7. 场景

场景按 **海侧 / 陆侧** 两部分布置，坐标约定 `+z` 为海侧、`-z` 为陆侧，码头前沿在 `z = 16`。

**陆侧**

- 陆域平台 **392 × 192 m**（原为 170 × 46 m 的窄条），可容纳完整的前沿作业带、堆场与后方建筑群
- 前沿作业带：高杆灯、系缆桩、隔离墩、波浪形地面标线

- 后方建筑：仓库 46 × 16 m、两层办公楼、三座筒仓（r = 5 m）、煤堆与矿堆
- 港区围墙沿三面边界（z = −174、x = ±194）闭合，界定陆域轮廓
- 后方横向主干道（双黄线），另加通行叉车 3 台、行道树 3 排

**海侧**

- 海面只在码头前方，900 × 300 m（原先为 700 × 700 m 铺满全场），纵深方向延伸到天际
- 码头前沿设压顶与护舷，沿岸线每 10 m 一组
- **散货船**：92 × 18.5 m，甲板高 4.2 m，舱口 60 × 14 m，舱内沙面 2.55 m（接近满载），船位 z = 30.5 m，与码头留约 5 m 靠泊间隙
- **自卸卡车**：车厢 9.2 × 2.62 m，底板 1.84 m，8 轮，停于码头面 z ≈ 0.8 m

## 9. 脚本控制

左侧「脚本控制」打开编辑面板，用几行指令编排动作，按顺序自动执行。每行一条，`#` 之后为注释，`Ctrl+Enter` 运行。

| 指令 | 参数 | 说明 |
|---|---|---|
| `回转` / `slew` | 角度 ° | 回转角 |
| `变幅` / `radius` | 幅度 m | 按工作幅度给定，内部反解臂架角 |
| `起升` / `hoist` | 高度 m | 抓斗底距轨面 |
| `抓斗` / `grab` | 0~100 | 开度百分比 |
| `行走` / `travel` | 位置 m | 大车行程 |
| `装载` / `load` | 0 / 1 | 斗内物料 |
| `等待` / `wait` | 秒 | 按仿真时间延时 |
| `速度` / `speed` | 倍 | 仿真倍速 |
| `复位` / `reset` | — | 回到初始姿态 |

示例：

```
速度 2
回转 -90
变幅 30
起升 3
抓斗 100      # 张斗入舱
等待 0.6
抓斗 0        # 闭斗抓取
等待 1.0
装载 1
起升 16
回转 0        # 转向卡车
变幅 23
起升 5
抓斗 100      # 卸料
装载 0
```

`装载` 指令仅用于特殊场合手动覆盖抓取量，正常抓料由上面的填充率模型自动计算，脚本里不必写。

执行规则：逐条下达目标值，等实测值进入容差才执行下一条；`等待` 按仿真时间计时（受倍速影响）；单条指令 45 s 未到位会标记超时并跳过。解析阶段遇到未知指令或缺参数会在状态栏报出行号，整段不执行。

## 10. AI 助手

右下角「AI」按钮打开对话面板。默认接 **DeepSeek**（`https://api.deepseek.com/v1`，`deepseek-chat`），点齿轮可改成任何 OpenAI 兼容接口——本地 Ollama、通义、Kimi 都行。

| 项 | 默认值 |
|---|---|
| API 地址 | `https://api.deepseek.com/v1` |
| 模型 | `deepseek-chat` |
| API Key | 空，需自行填入 |

Key 只写在本机 `localStorage`（键名 `portalcrane.ai.cfg`），不经过任何服务器。

**它能直接操作门机**，不是只会聊天。通过 function calling 提供四个工具：

| 工具 | 作用 |
|---|---|
| `set_crane` | 设置回转角 / 幅度 / 起升高度 / 抓斗开度 / 大车位置 |
| `run_script` | 执行多行指令脚本（复用上面的脚本引擎） |
| `get_status` | 读取当前机构位置、斗内物料、舱内余料、卡车装载 |
| `set_speed` | 设置仿真倍速 |
| `write_script` | 把脚本写入「脚本」页（可选立即运行） |
| `write_python` | 把 Python 程序写入「Python」页（可选立即运行） |

例如说「把抓斗转到船上，下到沙面抓一斗，再卸到卡车上」，它会连续调用 `set_crane` 与 `run_script`，并在两轮之间读状态确认。

> 浏览器直连第三方 API 会遇到 CORS 限制。DeepSeek 官方接口允许跨域直连；若换成不支持的地址，面板会提示 CORS 错误，此时需要一个允许跨域的网关或本地代理。

## 11. 结构悬停介绍

鼠标移到门机任意部件上（约 55 ms 后响应），弹出该部件的名称与作用说明，覆盖 12 个部件：门架、行走台车、回转支承与转台、塔架、人字架、主臂、象鼻梁、大拉杆、平衡重、齿条变幅机构、司机室、抓斗。

实现方式是给每个部件套一层**不可见的拾取体**（`MeshBasicMaterial({visible:false})`），用射线检测做命中判定——这样既能精确命中，又不会在画面上多出任何东西。臂架、象鼻梁、大拉杆、抓斗这四个运动部件用球体热点，每帧跟随各自的铰点/悬挂点更新位置。

配合原有的「标注」开关：标注是固定显示名称，悬停介绍给的是详细说明。

## 12. Python 控制

左侧「Py」按钮打开面板，在浏览器里跑**真正的 CPython**（Pyodide / WebAssembly），用于算法级控制。

首次运行需下载运行时（约 8 MB，10~30 秒），之后走浏览器缓存。需要联网。

### 接口

```python
crane.status()        # 返回 dict，见下表
crane.slew(deg)       # 目标回转角
crane.radius(m)       # 目标幅度
crane.hoist(m)        # 目标起升高度
crane.grab(v)         # 抓斗开度 0~1
crane.travel(m)       # 大车位置
crane.set(name, val)  # 通用设定
crane.speed(x)        # 仿真倍速
crane.log(*args)      # 输出到控制台
crane.reset()         # 复位
```

`status()` 返回字段：

| 字段 | 含义 |
|---|---|
| `slew` / `alpha` | 回转角、臂架仰角（度） |
| `radius` / `hoist` | 工作幅度、起升高度（m） |
| `grab` / `load` | 抓斗开度、斗内填充率（0~1） |
| `holdLevel` / `holdRemain` | 舱内料面高度、剩余比例 |
| `swayX` / `swayZ` | 吊物摆动偏角（rad） |
| `swayVX` / `swayVZ` | 吊物摆动角速度（rad/s） |
| `travel` / `truckLoad` | 大车位置、卡车装载斗数 |
| `grabPos` | 抓斗世界坐标 `{x,y,z}` |

### 程序结构

必须定义 `control(dt)`，引擎每帧调用一次（`dt` 为仿真时间步长）；`setup()` 可选，运行前执行一次。

```python
def setup():
    crane.slew(-90)
    crane.radius(30)

def control(dt):
    st = crane.status()
    if st["hoist"] > 5:
        crane.hoist(5)
```

### 曲线输出

Python 程序运行期间，引擎每帧记录一份完整状态（最多 2400 帧）。在程序里调用：

```python
crane.plot(["hoist", "load", "swayZ"])   # 常规曲线
crane.clear_plot()                        # 清空记录
```

**基线 / 算法对比**

做控制实验时要看"加算法前后"的差别，用分段标记：

```python
# 第一段（基线）
...
crane.mark("PD 补偿")      # 从这里开始算算法组
...
crane.plot_compare(["swayMag"])   # 画出对比：基线灰虚线 / 算法彩实线
```

两个内置示例已经是完整的对比流程：定量抓取先跑一轮固定浅插（抓不满），再跑一轮按料面自适应（抓满）；防摇摆先做一次无补偿回转（摆幅大），复位后再做 PD 补偿回转（摆幅小）。跑完自动弹出对比曲线，底部带图例。

可绘制的字段与 `status()` 一致（`hoist` / `load` / `swayZ` / `swayVZ` / `slew` / `radius` / `grab` 等），每条曲线独立缩放并标注上下限，右侧显示当前采样时长。

内置示例在关键节点已经调用了 `plot()`：定量抓取在闭斗完成时画 `hoist + load`，防摇摆启动时画 `slew + swayZ + swayVZ`。

### 两个内置示例

- **定量抓取**：按 `holdLevel` 算出应下放的高度（料面以下 1.15 m），开斗—下放—闭斗—提升，保证每斗都抓满
- **防摇摆**：用 `swayZ` / `swayVZ` 做 PD 反馈，把补偿量叠加到回转目标上抑制摆动

Python 适合闭环与算法；纯流程动作仍建议用脚本引擎（更轻，无需下载运行时）。

## 13. 实训模式

顶部「实训」按钮打开任务面板，面向《港口机械电气控制》《运动控制》类课程的仿真实训。五个任务由易到难，实时判定、自动计分，满分 500。

| 任务 | 内容 | 评分依据 |
|---|---|---|
| 一 · 机构定位 | 回转 −90°、幅度 30 m、起升 5 m 三点同时到位 | 三项误差越小分越高 |
| 二 · 水平变幅验证 | 只动变幅（30→24 m），观察抓斗高度变化 | 高度变化 < 0.6 m 满分 |
| 三 · 抓斗抓取作业 | 入舱抓满一斗并卸到卡车 | 按填充率给分，卸到场外不得分 |
| 四 · 轨迹规划 | 船→车转移，全程起升高度 ≥ 12 m | 合规且用时越短分越高 |
| 五 · 脚本编程 | 用指令脚本自动完成 抓取→回转→卸料 | 脚本跑通 + 填充率 + 用时 |

设计意图：

- **任务一**练四机构联动的坐标意识——回转和变幅都会改水平位置，起升只管高度
- **任务二**让学生亲手验证四连杆的效果：变幅 6 m 而高度只变几厘米，比讲十遍原理管用
- **任务三**把抓取量模型变成操作约束：插浅了抓不满，开度小了也抓不满
- **任务四**考路径规划：先起升过舱口再回转，直接横移会撞舱口围板（低于 12 m 判不合格）
- **任务五**要求把手工操作转成程序，对应"运动规划 → 程序实现"

### 扩展实验（结构认知与算法控制）

除上述五个操作任务外，平台还支持两类探究性实验，不参与自动评分，需提交实验报告。

2. 点击顶部「侧视」，从轨道方向观察四连杆的三角形关系，指出 A（臂架铰点）、B（臂架头）、C（抓斗悬挂点）、D（拉杆连接点）、E（拉杆铰点）五个关键点各落在哪个部件上；

**实验 B　Python 算法控制**

目的：把控制要求转成闭环算法，用曲线验证效果。

步骤：

1. 打开「Py」面板，先运行「定量抓取」示例，等控制台输出填充率后，曲线面板会显示 `hoist` 与 `load` 两条曲线。观察 `hoist` 的下降深度是否随 `holdLevel` 变化（连续抓几斗后重新运行，对比曲线）；
2. 再运行「防摇摆」示例，曲线显示 `slew` / `swayZ` / `swayVZ`。记录摆动角的最大幅值与衰减到 1/5 所需的时间；
3. 修改 `KP`、`KD` 两个参数重跑，至少测试三组取值，记录每组的第一摆幅值与稳定时间，找出较优组合；
4. （选做）把防摇摆的比例项去掉（`KP = 0`），只保留微分项，观察曲线变化并解释原因。

提交：三组参数对应的曲线截图、摆动幅值与稳定时间对比表、以及对"为什么纯比例控制会持续振荡"的分析。

## 16. 倍速实现

倍速只压缩**仿真时间轴**：，物理积分仍用固定 1/240 s 子步，所以摆动周期、阻尼衰减等动力学特性不会因倍速而失真（相当于整段录像快放）。相机过渡、面板刷新仍按真实时间，不受影响。

倍速提高时每帧子步数同步增加（4× 约 16 步/帧），上限按 4×@20 fps 留了余量。
