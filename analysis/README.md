# 回转工况抓斗摆动抑制对比实验

> 门座式起重机 GQ10-30，回转 0° → 90°，对比四种回转轨迹规划方式的摆动响应。
> 全部曲线由 Python 数值仿真生成，可直接复现。

---

## 1 实验目的

回转是门机最主要也最容易激起负载摆动的工况：臂架端点的切向加速度、离心加速度和
科氏加速度同时作用于悬挂抓斗，形成典型的球面摆强迫振动。本实验回答三个问题：

1. 手动操作、梯形加减速、经验 S 型加减速三种传统方式，摆动差别有多大？
2. 仅把加速度曲线"磨圆"（S 型）能不能抑制摆动？
3. 若用优化算法按摆动动力学整定 S 曲线参数，能把残余摆动压到多少？

## 2 物理模型

### 2.1 球面摆方程（回转坐标系）

吊点位于回转半径 `R` 处，抓斗简化为长 `L` 的单摆，在随臂架旋转的局部坐标系
（x 沿臂架向外、y 沿回转切向、z 竖直向上）中，以偏角 `u`（径向）、`v`（切向）描述：

```
x'' = -ω0²·L·sin(x/L) - 2ζω0·x' + 2ω·y' + ω²·(R+x) + α·y
y'' = -ω0²·L·sin(y/L) - 2ζω0·y' - 2ω·x' + ω²·y     - α·(R+x)
```

| 项 | 物理含义 |
| --- | --- |
| `-ω0²L·sin(x/L)` | 重力恢复力（保留非线性，大摆角不失真） |
| `-2ζω0·x'` | 结构与空气等效阻尼 |
| `2ω·y'` / `-2ω·x'` | 科氏加速度（回转时摆动的陀螺耦合） |
| `ω²(R+x)` / `ω²y` | 离心加速度（回转时负载向外甩） |
| `α·y` / `-α(R+x)` | 欧拉加速度（角加速度引起的切向惯性力） |

该方程由拉格朗日法对刚性球摆严格推导（`derive_model.py` 用 sympy 输出质量矩阵
`M11=1, M12=0, M22=cos²u` 与全部广义力项），在 `|x|,|y| << L` 时退化为经典线性模型。

### 2.2 参数（与三维仿真 `js/config.js` 一致）

| 参数 | 取值 | 说明 |
| --- | --- | --- |
| 回转半径 R | 26.0 m | 工作幅度 |
| 悬垂长度 L | 14.0 m | 吊点至抓斗质心 |
| 阻尼比 ζ | 0.03 | 摆动衰减时间常数 ≈ 40 s |
| 固有频率 ω0 | 0.837 rad/s | 摆动周期 **7.51 s** |
| 额定回转速度 | 1.6 r/min = 9.6 °/s | `V_RATED = 0.1676 rad/s` |
| 目标转角 | 90° | |

摆动周期 7.51 s 是关键尺度：轨迹的加速/减速段必须与这个周期"对相位"，否则减速段的
激励会与加速段叠加而不是抵消——这正是第 3 种方案（经验 S 型）失效的根本原因。

## 3 四种方案

| 方案 | 建模方式 | 关键参数 |
| --- | --- | --- |
| ① 模拟手动操作 | 分档推杆：0→45%→78%→100%→72%→45%→0，手柄推程 0.12 s + 传动滞后 0.30 s，叠加 ±1.2% 操作抖动，末端快速回杆 | 峰值 10.8 °/s（超额定 12%） |
| ② 梯形加减速 | 加速度阶跃，jerk 为冲击 | a = 0.035 rad/s²，T = 14.16 s |
| ③ S 型加减速 | 七段式 jerk 受限，参数凭经验 | a = 0.035 rad/s²，j = 0.10 rad/s³，T = 14.51 s |
| ④ 优化整定的 S 型 | 用**差分进化(DE)** 在 jerk 受限族内整定加/减速段的 a、j 及节拍，目标 = 过程峰值 + 停止后残余幅值 + 过程 RMS + 节拍代价 | a = 0.0264/0.0236 rad/s²，j = 0.209/0.210 rad/s³，T = 15.99 s |

方案 ④ 的约束：加速度与加加速度**不得超过**原经验 S 曲线的上限，节拍允许最多延长
1.8 s（用于相位补偿）。也就是说不靠"开得更猛"取胜，只靠相位整定。

## 4 结果

### 4.1 指标汇总（`out/metrics.csv`）

| 方案 | 节拍 T/s | 过程峰值摆角/° | 停后残余幅值/° | 停后 RMS/° | 衰减到 2°/s | 最大 jerk/(°/s³) |
| --- | --- | --- | --- | --- | --- | --- |
| ① 手动操作 | 14.26 | **17.46** | 4.85 | 2.97 | 34 | 207 |
| ② 梯形加减速 | 14.16 | 10.28 | 6.22 | 4.00 | 48 | **1003** |
| ③ 经验 S 型 | 14.51 | 10.26 | 6.20 | 3.96 | 45 | **5.7** |
| ④ 优化 S 型 | 15.99 | **8.04** | **0.56** | **0.38** | **≈0** | 12.8 |

- **峰值摆角**由加速度幅值决定：手动操作的档位阶跃把切向加速度顶到 15 °/s²，摆动冲到 17.5°；
  梯形与经验 S 型的加速度幅值相同（0.035 rad/s²），峰值几乎一模一样（10.28 / 10.26°）。
  这说明 **只把加速度曲线磨圆，并不能降低摆动峰值**。
- **残余摆角**由减速段与摆动周期的相位关系决定：梯形 6.22°、经验 S 型 6.20°，都要再等
  45~48 s 才能衰减到 2°；整定后 0.56°，停止后基本不再摆动。
- **加加速度**：梯形为阶跃（数值上 1003 °/s³），经验 S 型 5.7 °/s³，整定后 12.8 °/s³
  （仍在 S 型同一量级，结构冲击可控）。

### 4.3 鲁棒性（重要）

| 方案 | 残余幅值均值/° | 范围/° | 峰值均值/° |
| --- | --- | --- | --- |
| ① 手动操作 | 5.79 ± 2.08 | 4.45 ~ 9.95 | 17.80 |
| ② 梯形 | 6.35 ± 0.77 | 5.40 ~ 7.55 | 10.31 |
| ③ 经验 S 型 | 6.33 ± 0.77 | 5.38 ~ 7.53 | 10.29 |
| ④ 优化 S 型 | **0.63 ± 0.41** | 0.00 ~ 1.22 | **7.77** |

手动操作在停止时刻变化 ±0.8 s 时，残余摆角可以从 4.5° 跳到 10°——同一手法、不同松杆瞬间，
结果完全不同，这正是人工操作不可复现的原因。整定方案在同样的抖动下始终 < 1.3°。

## 5 结论

1. **平滑 ≠ 抑摆**。S 型曲线把 jerk 降低两个数量级（1003 → 5.7 °/s³），但峰值摆角与
   梯形完全相同、残余摆角也只差 0.02°，因为摆动由低频加速度包络与相位决定，而非 jerk 大小。
2. **抑制残摆的关键是"对相位"**。优化整定让减速段的激励与加速段引起的摆动相互抵消，
   残余幅值从 6.2° 降到 0.56°（−91%），衰减时间从 45 s 缩到 2 s 内。
3. **代价可量化**：整定方案多用 1.47 s 节拍（+10%），换取 10.7° 的峰值降幅和 5.7° 的残余降幅。
   若把节拍锁死（去掉相位补偿自由度），整定只能在加速度分配上做折中，抑制效果显著下降——
   **节拍余量本身就是一种抑摆资源**，这与输入整形的"以延时换抑振"是同一机理。
4. 手动操作的问题不是"摆得久"，而是**不可复现**：峰值最大（17.5°），残余在 4.5~10° 间随机，
   对司机技能与松杆时机高度敏感。

## 7 网页端集成

实验已集成到仿真网站：首页导航 **“摆动对比”** → `sway-lab.html`。

- **计算在浏览器里跑 Python**：页面加载 Pyodide（CPython 3.12 / WebAssembly，站点“Python 控制”
  用的是同一个内核），`js/sway-py.js` 里是与本目录 `sway_suppression.py` 同一套方程的纯 Python
  实现（球面摆 + RK4，不使用 numpy）。
- **首屏不等待**：`sway_suppression.py` 通过 `export_web()` 把标称工况的四条曲线写入
  `js/sway-data.js`（约 70 KB），页面先用它渲染；Python 内核就绪后按需实时重算。
- **可交互**：回转半径 R / 悬垂长度 L / 阻尼比 ζ 三个滑块实时改变物理响应；图表支持图例筛选、
  悬停读数、0–40 s 衰减视图切换；“重新整定”调用浏览器内的差分进化（小预算，18 代）按当前
  参数重新整定 S 曲线参数。
- **可分享工况**：`sway-lab.html?R=24&L=10&z=0.06` 直接打开指定工况。
- 修改模型后需重新生成预设数据：`python sway_suppression.py`（末尾会写 `js/sway-data.js`）。

## 8 模型边界

- 抓斗按质点单摆处理，未计入抓斗转动惯量与双绳吊具的回转约束；
- 阻尼按等效线性阻尼处理（ζ=0.03），未建模风载与司机/变频器的非线性；
- 回转机构按理想位置伺服处理，未包含电机转矩限幅与传动间隙；
- 手动操作曲线是统计化建模（档位+滞后+抖动），不代表某一台具体设备。
