# 门机司机室与气象仿真

从右上角视角菜单选择「司机操作」。默认使用司机座位相机，底部保留透明仪表条，右侧显示三路辅助监控。

## 操作室

司机室采用双侧操作台，包含弹性护套摇杆、彩色按钮、急停按钮、HMI 仪表、扶手座椅、踏板、门把手、窗框和雨刷。摇杆模型与键盘、屏幕摇杆输入同步摆动；面向前窗的实体急停、照明和雨刷按钮支持鼠标点击。

按「展开操纵台」显示触摸摇杆和功能按钮。拖动摇杆偏离中心控制速度，松手后回中并按原机构惯性减速。可同时操作两个摇杆；页面失焦、切出驾驶模式或急停时清除操纵输入。

| 操作 | 键盘 | 屏幕摇杆 |
|---|---|---|
| 回转 | A / D | 左摇杆左右 |
| 变幅 | W 伸臂 / S 收臂 | 左摇杆上下 |
| 起升 | ↑ 提升 / ↓ 下降 | 右摇杆上下 |
| 抓斗开合 | J 闭斗 / K 开斗 | 右摇杆左右 |
| 大车行走 | Z / X | 中央后退、前进按钮 |
| 急停 | 空格 | 红色急停按钮，再次点击解除 |

鼠标拖动画面环视。「看向抓斗」对准吊载，「正视操作台」恢复前窗视线。「操作灯」「雨刷」控制司机室的照明和雨刷动作。界面急停始终可见。关闭操纵台只收起屏幕控件，不停止驾驶模式；退出驾驶会释放输入并恢复外部相机。

## 辅助监控

三路窗口各自提供抓斗近景、象鼻梁俯视、卸料区、门机全景四个机位选择。抓斗近景跟随抓斗，卸料区机位跟随卡车位置。象鼻梁俯视采用前端滑轮旁的稳定向下机位，随门机回转、变幅和行走移动，画面顶部始终朝臂架前方；吊载摆动只改变画面内抓斗的位置，不带动镜头追踪或翻转。

监控使用独立相机，不改变主视角。窗口以约 6 帧/秒、360×202 分辨率刷新，以减少额外渲染开销；主画面仍按原帧循环运行。关闭监控、离开司机模式或页面隐藏后停止辅助渲染。手机端监控横排在顶部。

## 气象参数

在「设置 → 基本参数 → 气象环境」选择晴天 / 雨天、白天 / 夜间，设置 0—25 m/s 风速和北 / 东 / 南 / 西来向。司机操作台中的「气象设置」可直接打开该区域。白天和夜间与晴雨组合，共四种环境。

降雨改变能见度、天空、地面与水面的粗糙度，并显示随设定风速偏移的雨线。夜间降低环境照度并启用港区灯光。风速为用户设定的仿真值，不连接真实气象服务。

「风载影响吊载摆动」默认关闭。开启后，按 F/m = 0.5 ρ Cd A v² / m 计算简化水平加速度，ρ=1.225 kg/m³、Cd=1.2、A=6 m²、m=6500 kg，并加入原摆动方程。坐标约定：北为 −Z，东为 +X；风向表示来向。此近似忽略风场空间变化和吊载迎风面积变化，仅用于教学观察，不用于真实门机限风、停机或作业决策。
