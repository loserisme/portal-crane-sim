观察场景
左键拖动旋转，滚轮缩放，右键平移。右上角视角菜单可切换轴测、侧视、俯视、港区全景等视角。悬停部件可查看结构说明。

        
操控门机
左侧滑杆控制回转、变幅、起升、抓斗和大车行走。“作业循环”演示船舱抓料与卡车卸料；“复位”恢复初始作业状态。

        
司机操作与漫游
司机模式
A / D 回转，W / S 变幅，↑ / ↓ 起升，J / K 闭斗 / 开斗，Z / X 大车行走，空格急停，Esc 退出。
货车驾驶
W / S 加速与倒车，A / D 转向，空格制动，R 返回卸料位，Esc 退出。
自由漫游
点击场景后，WASD 移动、Q / E 降低 / 升高，拖动观察，Shift 加速，Esc 退出。

        
Python 与远程控制
左侧算法设计面板支持 setup() / control(dt) 算法；本地 Python GUI 可通过 WebSocket 页签连接，读取状态并控制门机。回转角单位为度，Python 返回的摆角单位为弧度。

        
使用设置窗口
拖动标题栏移动；标题栏获得焦点后可用方向键微调。点击“−”最小化，“＋”还原；“×”或 Esc 关闭。右上角齿轮可重新打开。关闭或最小化不会断开连接，停止远程控制请使用 WebSocket 页签中的按钮。
